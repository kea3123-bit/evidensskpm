Senarai Standard / Folder — Hierarki Asal ZIP

Struktur asal ZIP dipaparkan mengikut aras sebenar: 1 induk, 12 kategori, 71 folder aras ketiga dan 10 subfolder aras keempat (94 folder semuanya). Item berkod menjadi aspek Standard; folder anak kekal sebagai subfolder.

Nota: ZIP mengandungi 80 laluan .keep yang mewakili 94 folder berhierarki. Kod 3.1.2 ialah satu aspek dengan 10 anak folder mata pelajaran. Semua nama asal dipelihara; data sedia ada tidak ditimpa.

Struktur Folder Automatik

Struktur ini dibina daripada SENARAI STANDARD, bukan senarai ZIP statik. Folder sebenar diwujudkan di Drive apabila item ditambah atau disegerakkan oleh pentadbir.
